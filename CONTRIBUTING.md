# Contributing

## Local setup
1. Copy .env.example to .env.
2. Run docker compose up -d.
3. Run npm install.
4. Run npm run dev.

## Branching
- Use feature/* branches.
- Keep commits atomic.
- Follow conventional commits.

## Quality gates
- Unit tests pass.
- E2E smoke passes.
- No TypeScript errors.
- Accessibility checks for new UI paths.
